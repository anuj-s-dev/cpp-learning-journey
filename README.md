# C++ Learning Journey 🚀

This repository documents my journey of learning **C++**, from the very basics to more advanced topics like pointers, recursion, and arrays. It contains day-wise/topic-wise code examples and solved practice questions.

## 🛠️ Tech Stack

- **Language:** C++
- **Compiler:** GCC / G++ (or any standard C++ compiler)
- **Editor/IDE:** VS Code (or any C++ IDE of your choice)

## ▶️ How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/anuj-s-dev/C-.git
   cd C-
   ```
2. Navigate to the folder/topic you want to run.
3. Compile the `.cpp` file using g++:
   ```bash
   g++ filename.cpp -o output
   ```
4. Run the compiled program:
   ```bash
   ./output
   ```
